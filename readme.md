# ⚖️ 즐거운 밸런스 게임 사용 안내서

누구나 손쉽게 플레이하고 질문을 수정할 수 있는 밸런스 게임 웹 애플리케이션입니다.

---

## 📌 1. 파일 저장 방법
- 위의 `index.html` 코드 블록 상단의 **다운로드 버튼** 또는 **복사하기** 기능을 활용합니다.
- 내 컴퓨터의 **[바탕화면]** 이나 **[원하는 폴더]** 안에 **`index.html`** 이라는 이름으로 저장합니다.

---

## 📌 2. 실행하는 방법 (Windows 기준)
1. 저장한 **`index.html`** 파일을 찾습니다.
2. 마우스로 파일을 **더블 클릭**합니다.
3. 인터넷 연결이나 설치 없이, 크롬(Chrome)이나 엣지(Edge) 브라우저가 열리면서 **바로 게임이 실행**됩니다.
> 💡 **팁:** 스마트폰으로 전달해서 카카오톡 나에게 보내기 등으로 연 뒤 브라우저로 열면 휴대폰에서도 편하게 플레이할 수 있습니다.

---

## 📌 3. 질문 바꾸는 방법
1. `index.html` 파일에 마우스 오른쪽 클릭을 하고 **[연결 프로그램] ➔ [메모장]** 을 선택하여 엽니다.
2. `<script>` 아래쪽에 있는 `const defaultQuestions = [ ... ];` 부분을 찾습니다. (약 200번째 줄 부근)
3. 아래 형식처럼 `a`와 `b` 항목의 글자를 원하는 내용으로 수정하거나 추가/삭제하면 됩니다.

```javascript
const defaultQuestions = [
    { a: "바꾸고 싶은 A 내용", b: "바꾸고 싶은 B 내용" },
    { a: "평생 치킨만 먹기", b: "평생 피자만 먹기" },
    // 필요에 따라 마음껏 추가하거나 수정하세요!
];
```
4. 수정 후 메모장에서 **[Ctrl + S]** 를 눌러 저장한 뒤 브라우저를 **새로고침(F5)** 하면 바뀐 질문으로 게임을 즐길 수 있습니다!
